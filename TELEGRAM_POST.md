## Publicación 2 — Guía de Instalación (ES / EN)

```text
📘 GUÍA DE INSTALACIÓN / INSTALLATION GUIDE
👑 [ElKing Tech] SF Pro iOS System Font

[🇪🇸 ESPAÑOL]
1️⃣ Requisito (KernelSU / BakaSU / SukiSU / DirtyFrag):
   Ten instalado UN solo metamódulo de montaje (Mountify, meta-overlayfs, magic_mount_rs o Hybrid Mount). En Magisk no hace falta.
2️⃣ Descarga ElKingTech-SFPro-TempRoot_v1.0.0.zip (desde este canal o Releases en GitHub).
3️⃣ Instala desde tu gestor de Root → Módulos → Instalar desde almacenamiento.
4️⃣ Haz un Soft Reboot (deja desactivado Autorun mientras pruebas).
   💡 En Samsung One UI: deja la fuente "Predeterminada" en Ajustes → Pantalla.
   💡 Si alguna app no cambia: desactiva "Umount modules" para esa app y haz Soft Reboot (#umount).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[🇬🇧 ENGLISH]
1️⃣ Prerequisite (KernelSU / BakaSU / SukiSU / DirtyFrag):
   Have ONE mounting metamodule installed (Mountify, meta-overlayfs, magic_mount_rs, or Hybrid Mount). Not needed on Magisk.
2️⃣ Download ElKingTech-SFPro-TempRoot_v1.0.0.zip (from this channel or GitHub Releases).
3️⃣ Flash via Root Manager → Modules → Install from storage.
4️⃣ Perform a Soft Reboot (keep Autorun off while testing).
   💡 On Samsung One UI: keep the "Default" font selected in Display settings.
   💡 If an app still uses Roboto: disable "Umount modules" for that app and Soft Reboot (#umount).
```
